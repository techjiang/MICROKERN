# MICROKERN 内核设计

## 最小可信计算基

Ring 0 只提供 IPC、内存管理、调度、中断、Capability 和定时器。文件系统、网络协议栈、设备驱动全部作为独立用户态进程运行。

## 启动顺序

1. Bootloader 加载内核并传递内存映射。
2. 初始化串口，保证早期诊断可用。
3. 初始化物理页帧分配器与内核页表。
4. 初始化中断、定时器和调度器。
5. 启动第一个用户态进程：进程管理器。

## v1.0.0 当前实现

M1 可运行基线包含裸机入口、COM1 串口输出、panic handler 和 Buddy 分配器。页表、中断、调度、IPC 与 Capability 目录已预留接口占位，按里程碑逐步填充。未实现的模块不应被视为已上线能力。

## 发布边界

v1.0.0 用于架构验证、教学和二次开发起点。生产使用需等待 IPC、调度、隔离、用户态服务与多架构路径完成并通过集成测试。
